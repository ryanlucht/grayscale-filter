# Chrome Web Store Packages

Versioned ZIP files in this directory are ready for upload to the Chrome Web Store. Each archive contains only the extension runtime files and has `manifest.json` at its root.

Current package: [`grayscale-filter-v1.2.1.zip`](grayscale-filter-v1.2.1.zip)

Create or replace the archive for the current manifest version with:

```bash
npm run package:extension
```
